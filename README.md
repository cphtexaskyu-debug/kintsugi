# Kintsugi

Trace the real crack on your phone screen with your finger and turn it into a wallpaper
that celebrates it — kintsugi gold, flowers, lightning, constellations, and more.

**Use it:** open the site on the phone with the cracked screen → pick a style →
Start tracing → trace each crack branch (start at the impact point) → Done → Save →
set as lock screen.

For pixel-perfect alignment, install it: browser menu → **Add to Home Screen**, and open
it from there (runs fullscreen, no browser bars).

11 styles: Lacquer & Porcelain (kintsugi gold), Storm (lightning), Bloom (flowering vine),
Stars (constellation), Ember (molten fissure), Neon (tube signs), Circuit (PCB traces),
Arrow (bullseye strike), Shuriken, Meteor.

Single-file web app — no build, no dependencies, no tracking, nothing leaves your device.
